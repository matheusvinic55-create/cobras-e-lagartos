# Cobras & Lagartos

Experiência editorial independente de fã, em português, sem spoilers. Site estático em HTML, CSS e JavaScript, sem dependências de compilação.

## Desenvolvimento

Sirva a pasta `dist` com um servidor estático. No Vercel, use framework Other e Output Directory `dist`.

## Conteúdo

Premissa sem acontecimentos posteriores, apresentação dos personagens, cenografia, figurino e links de busca de músicas no Spotify. Não adicionar resumos de capítulos, mortes, revelações, desfechos ou transformações da trama.
